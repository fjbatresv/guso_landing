Guso is a patient-facing healthcare app built around appointments, prescriptions, health records, provider discovery, and reminders. This case study describes product and engineering work without publishing application source or operational configuration.

## Product at a glance

- Find doctors, clinics, and specialties.
- Manage appointments and prescriptions.
- Keep health record and insurance information accessible.
- Receive reminders and useful health content.

## System at a glance

The mobile client is built with Flutter. It communicates with two APIs: a legacy care API and a NestJS backend. The NestJS service uses TypeORM with MySQL, JWT guards, scheduled work, push notifications, and live notification events.
